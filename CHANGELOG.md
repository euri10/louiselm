# Changelog

## 0.1.0 (2026-09-18)


### ⚠ BREAKING CHANGES

* **broker:** canonical .beads must deny other-user access; ConfinementPlan requires the optional beads_replica field.
* **broker:** replace comment grants with typed mutation grants; require explicit request intent and a Beads operator handler.
* **workspace:** OperatorServer::serve_once requires a retention handler.
* **launcher:** require source snapshot/base digests in manifests. Record approved cleanup design; expiry and pins remain open.
* **broker:** canonical Session status uses schema /6 and requires conformance_admission.
* **config:** optional editor and service capabilities default off. Explicit choices preserve core chat and retained Run obligations.
* **launcher:** require launcher config/3 and authorization/3.
* **broker:** ReceiptStore::append takes optional report bytes.
* **ui:** Overview helpers take the owning Chat; global and list-based overview entry points are removed.
* **broker:** SessionStatus uses schema /5 with required recovery; RecoveryReadiness lives in launch_protocol with typed unavailable reasons.
* **broker:** Session status /4 returns dimension details. Broker status APIs no longer accept caller posture arguments.
* **runtime:** runtime registration rejects both removed fields.
* **cache:** Session manifests require cache_base_digest. Installed launch wiring and retention remain louiselm-d6fv.5.5.
* **broker:** receipt schemas advance to /4; remove the post-launch enable_commands API.
* **launch:** capability bindings name Run and Agent PID, not reaper.
* **skills:** sign per-Agent view membership
* **session:** prompt() returns a durable turn ID and dispatches only after asynchronous SQLite admission; sqlite3 is required.
* **session:** every Agent definition requires provider configuration.
* **sandbox:** development backends need a built louiselm-launch bootstrap selected with with_bootstrap.
* **rust:** Rust capture request APIs now borrow their inputs.
* **lua:** Session.new() returns Registry directly; drop Api.registry and the session.api module.
* **config:** drop removed skills.full_content key
* **commands:** replace the old session and inbox command names with the new prefixed forms.
* **agents:** chat commands no longer infer an Agent from LOUISELM_AGENT_COMMAND or DeepSeek defaults.
* **capture:** pairing QR v1, serve --bind, pair --url, and capture.receiver_url are removed. Configure one private receiver profile before pairing.
* **skills:** Local skill discovery now requires lyaml for Lua 5.1.
* **skills:** remove skills.full_content and native_supported policy inference. Use per-agent skills.policy overrides.\n\nRefs louiselm-376
* **capture:** add durable speech intake
