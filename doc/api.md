# LouiseLM Public API Appendix

Generated by `scripts/generate-api-appendix` from LuaCATS annotations via
`lua-language-server --doc`. Do not edit by hand.

Scope: the established extension boundaries only -- the headless Session
API, typed events, permission policies, and Agent configuration
(AGENTS.md section 1). ACP transport internals, UI, schema machinery,
mocks, and development helpers are intentionally excluded. AGENTS.md
remains the sole Agent-facing (AX) contract; this appendix is a human
API reference.

- `command: string` -- Executable to start.
- `env: table<string, string>?` -- Environment variables for the process.
- `latest: (louiselm.agent.CommandCheck)?` -- Optional command that resolves the latest available version.
- `options: table<string, unknown>?` -- Agent-specific options. `options._meta`, when present, is threaded
- `provider: string|louiselm.agent.ProviderPrefixes|louiselm.agent.ProviderRoute[]` -- Explicit access/quota service, exact option routes, or literal option prefixes; required before prompting.
- `skills: (louiselm.agent.SkillConfig)?` -- Effective Agent Skills policy after normalization.
- `transcript_layout: string?` -- Optional Provenance integration for locating this Agent's historical transcripts on disk; live chat transcripts need no configuration.
- `upgrade: (string|string[])?` -- Upgrade executable and arguments, or nonblank manual update instructions. Displayed only, never executed by LouiseLM; only argv can join the combined upgrade command.
- `version: (louiselm.agent.CommandCheck)?` -- Optional override for querying the installed version, when `command args... --version` is not the right invocation (e.g. a subcommand-based CLI).

### louiselm.agent.HealthResult

- `available: boolean` -- Whether the executable is on PATH.
- `code: integer?` -- Version process exit code.
- `command: string` -- Checked executable.
- `error: string?` -- Specific availability or version failure.
- `latest_error: string?` -- Why the latest-version check did not resolve a version.
- `latest_version: string?` -- First line returned by the configured latest-version check.
- `ok: boolean` -- Whether the executable responded with a version.
- `outdated: boolean?` -- True when both the installed and latest versions resolved and differ.
- `version: string?` -- First line returned by `--version`.

### louiselm.agent.ProcessResult

- `code: integer` -- Process exit code.
- `signal: integer` -- Process signal, if terminated by a signal.
- `stderr: string` -- Captured standard error.
- `stdout: string` -- Captured standard output.
