*louiselm.txt*  LouiseLM human reference


==============================================================================
Overview                                                      *louiselm*

  LouiseLM is an ACP-first Neovim client with an interactive chat and a
  headless Session API.

  Configure at least one Agent with require('louiselm').setup(), then use
  :LouiselmChat to start a Session.

  Use :checkhealth louiselm to validate configured Agents, local skills, and
  capture tools. Health output is operational evidence, not a substitute for
  this reference.

  Sessions remain bound to their Agent. A Handoff creates a new Session with a
  configured Agent, including the current Agent, and seeds it with your
  takeover task and a compacted source transcript. The source Session remains
  attached.

==============================================================================
Sessions                                                      *louiselm-sessions*

  A Session is bound to one Agent for its lifetime. Use :LouiselmSessionNew to
  start another Session without stopping the current one, and
  :LouiselmSessionSwitch to focus an attached Session.

  A Handoff creates a new Session with a configured Agent after you fill in
  its takeover task and review the compacted source transcript. The source
  Session remains attached.

==============================================================================
Workflow                                                      *louiselm-workflow*

  Configure an Agent, start or resume a Session, queue optional context, then
  submit a prompt. Respond deliberately to permission requests and cancel a
  current turn when the intent changes.

==============================================================================
Permissions                                                   *louiselm-permissions*

  Sessions ask a human to answer ACP permission requests by default.
  Persistent choices remain scoped to the configured Agent, exact adapter
  command and arguments, and Session workspace.

==============================================================================
Context and skills                                            *louiselm-context*

  Use the context commands to queue a buffer, visual selection, file, or skill
  for the next prompt. Queued context is sent only when you submit that
  prompt.

==============================================================================
Troubleshooting                                               *louiselm-troubleshooting*

  Run :checkhealth louiselm to validate configuration and local tool
  availability. For Session-specific reports, :LouiselmSessionId copies the
  Agent-scoped ACP Session identifier.

Configuration                                                 *louiselm-configuration*

------------------------------------------------------------------------------
agents                                                        *louiselm-config-agents*
    Type: string-keyed map of table
    Default: {}
    Description: Named ACP agent processes.

------------------------------------------------------------------------------
agents.<name>.args                                            *louiselm-config-agents-name-args*
    Type: array of string
    Default: {}
    Description: Arguments passed after the executable.

------------------------------------------------------------------------------
agents.<name>.capabilities                                    *louiselm-config-agents-name-capabilities*
    Type: array of string
    Default: {}
    Description: Capability tags this agent declares support for (e.g.
    "image-generation"), matched against `needs-capability:*` beads labels by
    the agent selecting work; louiselm does not read beads or route work
    itself.

------------------------------------------------------------------------------
agents.<name>.command                                         *louiselm-config-agents-name-command*
    Type: string
    Description: Executable to start.

------------------------------------------------------------------------------
agents.<name>.env                                             *louiselm-config-agents-name-env*
    Type: string-keyed map of string
    Default: {}
    Description: Environment variables passed to the process.

------------------------------------------------------------------------------
agents.<name>.latest                                          *louiselm-config-agents-name-latest*
    Type: table
    Default: {}
    Description: Optional command that resolves the agent's latest available
    version, e.g. `npm view <pkg> version`; omission disables the staleness
    check.

------------------------------------------------------------------------------
agents.<name>.latest.args                                     *louiselm-config-agents-name-latest-args*
    Type: array of string
    Default: {}
    Description: Arguments passed after the executable.

------------------------------------------------------------------------------
agents.<name>.latest.command                                  *louiselm-config-agents-name-latest-command*
    Type: string
    Description: Executable that prints the latest available version.

------------------------------------------------------------------------------
agents.<name>.latest.env                                      *louiselm-config-agents-name-latest-env*
    Type: string-keyed map of string
    Default: {}
    Description: Environment variables passed to the process.

------------------------------------------------------------------------------
agents.<name>.provider                                        *louiselm-config-agents-name-provider*
    Type: one of: string, array of table
    Description: Required access/quota service: a fixed name or nonempty
    routes matching exact advertised option IDs and typed values. Exactly one
    route must match before each prompt; Model display names never determine
    Provider.

------------------------------------------------------------------------------
agents.<name>.provider[].options                              *louiselm-config-agents-name-provider-options*
    Type: string-keyed map of one of: string, boolean

------------------------------------------------------------------------------
agents.<name>.provider[].provider                             *louiselm-config-agents-name-provider-provider*
    Type: string

------------------------------------------------------------------------------
agents.<name>.skills                                          *louiselm-config-agents-name-skills*
    Type: table
    Default: {}
    Description: Agent-specific Agent Skills policy override; paths remain
    global and the effective value is fixed when a session is created.

------------------------------------------------------------------------------
agents.<name>.skills.policy                                   *louiselm-config-agents-name-skills-policy*
    Type: string
    Description: Override the global Agent Skills policy: native delegates to
    the adapter, inject uses LouiseLM discovery, and off disables automation;
    omission inherits the global policy.

------------------------------------------------------------------------------
agents.<name>.transcript_layout                               *louiselm-config-agents-name-transcript-layout*
    Type: string
    Default: ""
    Description: Optional Provenance layout override for this Agent's
    historical transcripts: claude, codex, openai-compatible, or copilot; live
    chat transcripts need no configuration; omission searches all supported
    layouts.

------------------------------------------------------------------------------
agents.<name>.upgrade                                         *louiselm-config-agents-name-upgrade*
    Type: array of string
    Default: {}
    Description: Optional upgrade executable and arguments, e.g. { 'npm',
    'install', '-g', 'my-agent@latest' }. Shown as a shell-escaped command in
    outdated-Agent warnings, never executed. Set this for the actual
    installation (including local builds); omission leaves upgrade guidance
    unavailable. Multiple commands are joined with &&, stopping on failure.

------------------------------------------------------------------------------
agents.<name>.version                                         *louiselm-config-agents-name-version*
    Type: table
    Default: {}
    Description: Optional override for querying the installed version,
    verbatim (nothing is auto-appended). Use when `command args... --version`
    is not the right invocation, e.g. a subcommand-based CLI wrapped by a
    debug script.

------------------------------------------------------------------------------
agents.<name>.version.args                                    *louiselm-config-agents-name-version-args*
    Type: array of string
    Default: {}
    Description: Arguments passed after the executable.

------------------------------------------------------------------------------
agents.<name>.version.command                                 *louiselm-config-agents-name-version-command*
    Type: string
    Description: Executable that prints the installed version.

------------------------------------------------------------------------------
agents.<name>.version.env                                     *louiselm-config-agents-name-version-env*
    Type: string-keyed map of string
    Default: {}
    Description: Environment variables passed to the process.

------------------------------------------------------------------------------
beads                                                         *louiselm-config-beads*
    Type: table
    Default: {}
    Description: Beads issue-inspector settings.

------------------------------------------------------------------------------
beads.sibling_roots                                           *louiselm-config-beads-sibling-roots*
    Type: array of string
    Default: {}
    Description: Directories globbed one level for a sibling
    `.beads/beads.db`, tried in order when the cursor is on a full issue ID
    belonging to a different workspace's prefix; empty disables
    cross-workspace lookup.

------------------------------------------------------------------------------
capture                                                       *louiselm-config-capture*
    Type: table
    Default: {}
    Description: Durable speech-capture command settings.

------------------------------------------------------------------------------
capture.recorder                                              *louiselm-config-capture-recorder*
    Type: array of string
    Default: {}
    Description: Recorder argv with one {output} placeholder.

------------------------------------------------------------------------------
capture.service                                               *louiselm-config-capture-service*
    Type: array of string
    Default: {}
    Description: Capture-service argv prefix.

------------------------------------------------------------------------------
context                                                       *louiselm-config-context*
    Type: table
    Default: {}
    Description: Project-context injection settings.

------------------------------------------------------------------------------
context.instructions_file                                     *louiselm-config-context-instructions-file*
    Type: string
    Default: ""
    Description: Project-root filename attached as a resource_link on new
    sessions; empty disables.

------------------------------------------------------------------------------
keymaps                                                       *louiselm-config-keymaps*
    Type: boolean
    Default: true
    Description: Install LouiseLM's global default keymaps; false disables
    them.

------------------------------------------------------------------------------
skills                                                        *louiselm-config-skills*
    Type: table
    Default: {}
    Description: Agent Skill discovery and injection settings.

------------------------------------------------------------------------------
skills.paths                                                  *louiselm-config-skills-paths*
    Type: array of string
    Default: {}
    Description: Global directories searched for Agent Skills; relative paths
    resolve against each session workspace.

------------------------------------------------------------------------------
skills.policy                                                 *louiselm-config-skills-policy*
    Type: string
    Default: "native"
    Description: Default Agent Skills policy: native delegates to the adapter,
    inject uses LouiseLM discovery, and off disables automation.
